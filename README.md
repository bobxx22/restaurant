# Шаблон: ресторан / кафе

Одностраничный сайт-визитка на Next.js, весь текст на украинском.
Сверху видео, акции, потом меню с фото. Гость нажимает «Хочу», сайт считает сумму,
а список выбранного он показывает официанту. Онлайн-заказа нет.

## Как сделать сайт под нового клиента

1. Скопировать папку `restaurant` → `имя-клиента`.
2. **Фото**: положить в `images-src/` (папки `hero`, `promo`, `menu`, `about`) и запустить `npm run images`.
   Скрипт сожмёт их в лёгкие `.webp` в `public/images/` (20 МБ → ~2 МБ).
3. **Видео**: `public/video/hero-desktop.mp4` (16:9) и `hero-mobile.mp4` (9:16), до 3 МБ каждое.
4. **Данные**: всё в `src/data/site.ts`:
   - название, слоган, описание, телефон, адрес, домен (`url`), соцсети, график;
   - акции (`promos`): заголовок, текст, фото, `theme` (`light` — тёмный текст, `dark` — белый);
   - меню (`menu`): у каждого блюда свой `id` латиницей и `image`. Нет фото — будет заглушка.
5. Цвета при желании — в `src/app/globals.css` (`--accent`, `--background` и т.д.).

## Эффект искр

`src/components/HeroEmbers.tsx`, библиотека [shaders](https://shaders.com) (MIT).
Грузится отдельно, после страницы, и только в браузерах с WebGPU. Остальные видят обычное видео.
Чтобы отключить, убрать `<HeroEffects />` из `src/components/Hero.tsx`.

## Команды

```bash
npm install      # один раз
npm run images   # сжать фото из images-src/
npm run dev      # локальный просмотр: http://localhost:3000
npm run build    # готовый сайт в папке out/
```

Папку `out/` заливать на Cloudflare Pages или Netlify. Сайт статический, сервер не нужен.
